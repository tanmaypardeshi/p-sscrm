# P-SSCRM Website

## What is P-SSCRM?

Software usually isn't built entirely by one team — it's assembled from open-source libraries, tools, and other people's code. That chain of dependencies is called the "software supply chain," and if any link in it is careless or compromised, the whole thing is at risk.

**P-SSCRM (Proactive Secure Software Supply Chain Risk Management)** is a framework that helps organizations check how well they're managing that risk. It breaks the problem down into a few big topics ("Groups," like Governance or Deployment), each with more specific practices, each broken down further into concrete, checkable items ("Controls"). Each of those items is also mapped to other well-known security standards (like NIST guidelines or SLSA), so an organization can see how their existing work already lines up with P-SSCRM.

## What this website is

This site is a browsable, easy-to-read version of the P-SSCRM framework. You can look through every Group, Practice, and Control, see how it maps to other standards, and see which version of the framework is current.

The framework content itself isn't written here — it's pulled in from the official P-SSCRM project on GitHub, so this site always reflects the real, maintained version of the framework. See `DEVELOPMENT.md` for how that works and how to run the site yourself.
