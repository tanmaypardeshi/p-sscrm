Frameworks

P-SSCRM was built by analyzing and unifying ten government and industry standards and frameworks for software supply chain security. Every Control in P-SSCRM is mapped to one or more of these sources.

  • 800-161

    NIST Cybersecurity Supply Chain Risk Management Practices for Systems and Organizations (800-161r1) - only the subset of controls specifically identified in this document as mapping back to the Executive Order

  • BSIMM

    Building Security In Maturity Model Version 15 (BSIMM)

  • CNCF-SSC

    Cloud Native Computing Foundation – Software Supply Chain Best Practices (CNCF)

  • EO

    Executive Order 14028 (EO)

  • OSSF-Scorecard

    OpenSSF Scorecard metrics

  • OWASP-SCVS

    Open Web Application Security Project Software Component Verification Standard Version 1.0 (OWASP-SCVS)

  • SLSA

    Supply-chain Levels for Software Artifacts v1.2 (SLSA)

  • SSDF

    NIST Secure Software Development Framework version 1.1 (SSDF)

  • SSDF-AI

    NIST Secure Software Development Practices for Gen AI version 1.1 (SSDF-AI)

  • Self-attestation

    DHS/CISA Secure Software Self-Attestation Common Form
